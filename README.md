# Hwang Hon Sports System

Sistema de gestión deportiva para el Club Hwang Hon Hapkido.

## Descripción

Proyecto de desarrollo de software orientado a la gestión y organización de la información deportiva y administrativa del Club Hwang Hon Hapkido.

El sistema busca centralizar la información de los deportistas y facilitar procesos relacionados con:

- Gestión de información de deportistas.
- Evaluación y seguimiento deportivo.
- Estadísticas para competencias.
- Historial de participación y resultados.
- Evaluaciones para ascenso de cinturón.
- Gestión y generación de documentación.
- Información administrativa del club.
- Preparación de información para procesos de inscripción a competencias.

El proyecto parte de los procesos y documentación actualmente utilizados por el club, con el objetivo de digitalizarlos, organizarlos y facilitar su gestión.

## Alcance inicial

El sistema está diseñado inicialmente para el **Club Hwang Hon Hapkido**.

Se contempla que la arquitectura pueda permitir futuras ampliaciones o integraciones con otros procesos deportivos, como las Escuelas de Formación del IMRDS, sin que estas formen parte del alcance inicial del proyecto.

## Estado del proyecto

🚧 **En desarrollo — Fase de investigación y análisis.**

Actualmente se encuentra en proceso de recopilación, análisis y documentación de los procesos reales del club. Los requerimientos y funcionalidades definitivas serán establecidos antes de iniciar la implementación.

## Metodología

El proyecto sigue una metodología de desarrollo por etapas:

1. Análisis e investigación.
2. Documentación.
3. Diseño de base de datos.
4. Definición de lógica de negocio.
5. Arquitectura backend.
6. Desarrollo backend.
7. Desarrollo frontend.
8. Integración.
9. Pruebas.
10. Despliegue.

No se inicia la implementación hasta contar con una definición suficientemente clara de los procesos y requerimientos correspondientes.

## Tecnologías

Las tecnologías definitivas serán seleccionadas durante la fase de diseño técnico, de acuerdo con las necesidades reales del proyecto.
